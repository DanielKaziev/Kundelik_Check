# Kundelik_Check

## Описание
Kundelik_Check — это веб-приложение, которое позволяет школьникам и их родителям рассчитывать оценки за четверть или за отдельные задания. Функциональность приложения обеспечивает простоту и точность в определении оценок, помогая пользователям легко находить актуальную информацию об успеваемости в школе.

## Как начать

1. Скачайте проект:
   - Нажмите на кнопку "Code" на странице репозитория и выберите "Download ZIP".
   - Распакуйте архив на вашем компьютере.

2. Откройте файл `src/index.html` в вашем браузере. Это главный файл приложения, который запускает его работу.

## Возможности

- Удобный интерфейс для расчета оценок.
- Быстрая загрузка и стабильная работа.
- Поддержка современных браузеров.

## Часто задаваемые вопросы

### Как открыть приложение?
Просто откройте файл `src/index.html` в любом современном браузере, таком как Google Chrome, Mozilla Firefox или Microsoft Edge.

### Нужно ли что-то устанавливать?
Нет, приложение работает прямо в браузере. Вам не нужно ничего дополнительно устанавливать.

### Что делать, если что-то не работает?
Если вы столкнулись с проблемой, попробуйте обновить страницу в браузере. Если это не помогло, свяжитесь с разработчиком через страницу репозитория.
